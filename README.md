# FoodSaver – Surplus Food Donation and Redistribution System

## Project Description
FoodSaver is a software project designed to reduce food wastage by connecting food donors with verified NGOs and charitable organizations.

## Objectives
- Reduce food wastage.
- Encourage food donation.
- Connect donors with recipients.
- Simplify surplus food redistribution.

## User Roles
1. **Donor:** Restaurants, hotels, canteens and event organizers.
2. **Recipient:** Verified NGOs and charitable organizations.
3. **Administrator:** Manages users and verifies recipients.

## Key Features
- User registration and login.
- Recipient verification.
- Food donation listing.
- Search and request donations.
- Accept or reject requests.
- Donation status tracking.
- Donation history.
