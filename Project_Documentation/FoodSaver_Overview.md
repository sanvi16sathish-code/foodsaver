# FoodSaver – Project Overview

## 1. Introduction
FoodSaver is a Surplus Food Donation and Redistribution System designed to reduce food wastage by connecting food donors with needy people through verified NGOs and organizations.

## 2. Objectives
- Reduce food wastage.
- Connect food donors with NGOs.
- Make surplus food donation easier.
- Promote social responsibility.
- Support food redistribution.

## 3. Main Users

### Donors
Restaurants, hotels, canteens and event organizers who donate surplus food.

### Recipients
Verified NGOs and charitable organizations that request available food.

### Administrator
Manages users, verifies recipients and monitors donations.

## 4. Main Features
- User registration and login.
- Recipient verification.
- Add and manage food donations.
- Search available food.
- Request food donations.
- Accept or reject requests.
- Track donation status.
- View donation history.

## 5. Working Process
1. Donor registers and logs in.
2. Donor adds surplus food details.
3. Verified recipients browse available donations.
4. Recipients send food requests.
5. Donors accept or reject requests.
6. Both parties receive status updates.
7. Recipients arrange food collection.

## 6. Technologies
- Frontend: HTML, CSS and JavaScript.
- Backend: Planned application logic.
- Database: Planned data storage.
- Version Control: Git and GitHub.

## 7. Conclusion
FoodSaver aims to reduce food wastage and support communities by providing a simple platform for surplus food donation and redistribution.
