# Git Commands – FoodSaver Project

## 1. Git Clone
Downloads a repository from GitHub to the local computer.
Command: git clone repository_url

## 2. Git Status
Displays the current status of files.
Command: git status

## 3. Git Add
Stages files for committing.
Command: git add .

## 4. Git Commit
Saves changes to the local repository.
Command: git commit -m "Initial commit"

## 5. Git Push
Uploads local commits to GitHub.
Command: git push origin main

## 6. Git Pull
Downloads the latest changes from GitHub.
Command: git pull origin main

## 7. Git Branch
Creates a new branch.
Command: git branch feature-login

## 8. Git Merge
Combines changes from one branch into another.
Command: git merge feature-login

## Conclusion
Git commands help developers manage project versions, collaborate and maintain source code efficiently.
